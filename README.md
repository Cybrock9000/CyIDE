# CyIDE
A small lightweight IDE made in pygame


## Controls:

F1 = Save
F2 = Load
F3 = Open Panel
F4 = Run Project (only works with python)
Page UP = Scroll up
Page Down = Scroll Down
Page Up/Down + Shift = Faster Scroll
Page Up/Down + Ctrl = Scroll right/left
Escape = Settings (will restart the IDE but will save your progress)


## How to run:

Download latest release and extract the zip
Run Cyeditor.exe

## Plugins:

Look at example.py or any other plugin to see how to create plugins

## Themes:

You can create you own theme by modifying p.png and applying it in the settings
Themes work by taking the p.png and looking at certan pixels in a row and applying it to the IDE
